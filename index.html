Pastel Sweeper

Thank you for downloading Pastel Sweeper!

Pastel Sweeper is a colorful clone of Windows XP Minesweeper, focused on simple, addictive gameplay.

Save Location

  • Windows: %USERPROFILE%\AppData\Roaming\Pastel Sweeper\
  • macOS: $HOME/Library/Application Support/Pastel Sweeper/
  • Linux: $HOME/.Pastel Sweeper/

Controls

Mouse

  • Left click: Reveals hidden tiles
  • Right click: Marks tiles as mines or question marks
  • Middle click / Left + Right click: Reveals safe tiles when the correct number of mines have been marked

Keyboard

  • N: New game
  • B: Beginner difficulty
  • I: Intermediate difficulty
  • E: Expert difficulty
  • C: Open custom game popup
  • M: Toggle question marks
  • S: Toggle sound
  • T: Open best times popup
  • A: Open about popup
  • X: Exit game
